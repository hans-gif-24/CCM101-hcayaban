## 📚 Portfolio Contents

### ☁️ Laboratory 01 — Welcome to the Cloud

The first laboratory introduced me to the fundamentals of working with a **cloud-based Linux environment**. The activities included using Linux commands, gathering system information, managing files and directories, creating Markdown documentation, and practicing GitHub version control.

### ☁️ Laboratory 02 — Build the Cloud Infrastructure Blueprint

The second laboratory focused on understanding the **fundamental components of cloud infrastructure** and how they work together in a cloud environment.

The activities included investigating a Linux cloud server using the **KillerCoda Playground**, analyzing CPU, memory, storage, and network resources, identifying cloud infrastructure components, designing a basic cloud architecture, and comparing the core services of **AWS, Microsoft Azure, and Google Cloud Platform (GCP)**.

The laboratory also strengthened my skills in **Linux system administration, cloud infrastructure analysis, Markdown documentation, Git, and GitHub**.
