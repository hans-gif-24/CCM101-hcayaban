# ☁️ Checkpoint 4 – Cloud Platform Recommendation Challenge

This activity compares different cloud platforms and determines which provider is most appropriate for each organization. The recommendations are based on factors such as budget, existing technologies, performance, scalability, and business objectives.

---

## 🚀 Client A – Startup Company

### 📌 Scenario

A startup is preparing to launch a new mobile application. It has a limited budget but expects its number of users and business activities to increase quickly in the future.

### 💡 Recommendation

| **Requirement**                   | **Answer**                                                                                                                                                                                                                                                                             |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ☁️ **Recommended Cloud Platform** | **Google Cloud Platform (GCP)**                                                                                                                                                                                                                                                        |
| 💭 **Recommendation**             | GCP is a good option for the startup because it can start with the resources it currently needs and increase them as the application grows. This helps reduce the need for expensive physical hardware while providing useful services for developing and running mobile applications. |
| 🔥 **Service 1**                  | **Firebase** – Provides tools that can help developers build, test, and manage mobile applications.                                                                                                                                                                                    |
| ⚡ **Service 2**                   | **Cloud Run** – Allows applications to run in the cloud without requiring users to manage physical servers.                                                                                                                                                                            |
| 🗄️ **Service 3**                 | **Cloud Storage** – Can store application files such as images, videos, and other data.                                                                                                                                                                                                |
| 🛢️ **Service 4**                 | **Cloud SQL** – Provides a managed relational database for application information.                                                                                                                                                                                                    |

## 🎓 Client B – University

### 📌 Scenario

A university currently uses Windows Server, Microsoft 365, and Active Directory. The university wants to move some of its existing services to cloud-based infrastructure.

### 💡 Recommendation

| **Requirement**                   | **Answer**                                                                                                                                                                                                                           |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ☁️ **Recommended Cloud Platform** | **Microsoft Azure**                                                                                                                                                                                                                  |
| 💭 **Recommendation**             | Azure is a suitable choice because the university already depends on Microsoft technologies. Its compatibility with Windows Server, Microsoft 365, and Microsoft Entra ID can make the migration to cloud services easier to manage. |
| 🖥️ **Service 1**                 | **Azure Virtual Machines** – Allows Windows Server workloads and applications to run in the cloud.                                                                                                                                   |
| 🔐 **Service 2**                  | **Microsoft Entra ID** – Manages user identities, authentication, and access to resources.                                                                                                                                           |
| 🌐 **Service 3**                  | **Azure App Service** – Provides a platform for hosting websites and web applications.                                                                                                                                               |
| 🗄️ **Service 4**                 | **Azure Storage** – Can store documents, files, backups, and other digital information.                                                                                                                                              |

## 🌎 Client D – Global E-Commerce Company

### 📌 Scenario

A multinational e-commerce company serves customers from many parts of the world. It needs reliable cloud infrastructure that can stay available during periods of heavy traffic and automatically adjust to changes in demand.

### 💡 Recommendation

| **Requirement**                   | **Answer**                                                                                                                                                                                                                                                         |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ☁️ **Recommended Cloud Platform** | **Amazon Web Services (AWS)**                                                                                                                                                                                                                                      |
| 💭 **Recommendation**             | AWS is a suitable choice because of its large global infrastructure, which can support customers from different regions. Its scaling and load-balancing services can help an online store handle increased traffic while maintaining availability and performance. |
| 🖥️ **Service 1**                 | **Amazon EC2** – Provides scalable virtual servers for websites and applications.                                                                                                                                                                                  |
| 📈 **Service 2**                  | **EC2 Auto Scaling** – Automatically adjusts computing resources based on demand.                                                                                                                                                                                  |
| ⚖️ **Service 3**                  | **Elastic Load Balancing** – Distributes incoming traffic across multiple servers to improve reliability.                                                                                                                                                          |
| 🚀 **Service 4**                  | **Amazon CloudFront** – Delivers website content efficiently to users around the world.                                                                                                                                                                            |
| 🛢️ **Service 5**                 | **Amazon RDS** – Provides a managed database service for storing and managing application data.                                                                                                                                                                    |

# 🏁 Summary

Each major cloud provider has different strengths, making each one suitable for specific organizations and workloads.

| **Cloud Provider**                 | **Best Suited For**                                                     |
| ---------------------------------- | ----------------------------------------------------------------------- |
| 🟧 **Amazon Web Services (AWS)**   | 🏢 Large enterprises and 🌎 applications serving users around the world |
| 🔵 **Microsoft Azure**             | 🪟 Organizations that heavily depend on Microsoft technologies          |
| 🔴 **Google Cloud Platform (GCP)** | 🚀 Startups, 🤖 AI/ML workloads, and ☸️ Kubernetes-based applications   |

### 🎯 Overall Recommendation

* 🟧 **AWS** → Best for **global-scale applications and large enterprises**
* 🔵 **Azure** → Best for **Microsoft-centered environments**
* 🔴 **GCP** → Best for **startups, AI/ML, and Kubernetes workloads**

> 💡 **Key Takeaway:** No single cloud provider is the best choice for every organization. The appropriate platform depends on factors such as budget, existing technologies, performance requirements, scalability, and the organization's long-term goals.
