
# ☁️ Cloud Infrastructure Components

## 🧠 1. Compute Resources

### 🔍 Example

An **Intel Xeon processor** with several virtual CPU cores allocated to the cloud environment.

### 🎯 Purpose

Compute resources supply the processing capacity needed to run applications, execute commands, and support various services.

### ☁️ Importance in Cloud Computing

Compute resources are essential for handling workloads and enabling cloud-based applications and services to operate effectively.

### 🖥️ KillerCoda Environment

The Linux server within KillerCoda provides **virtual CPU resources** that process commands, applications, and other workloads.

---

## 💾 2. Storage Resources

### 🔍 Example

A virtual storage device such as **`/dev/vda1`**.

### 🎯 Purpose

Storage resources provide the necessary space for the operating system, applications, configuration files, and user-generated data.

### ☁️ Importance in Cloud Computing

Cloud storage makes it possible to save, retrieve, and manage data in a dependable and accessible manner.

### 🖥️ KillerCoda Environment

The KillerCoda Linux environment includes **virtual disk storage** used to hold the operating system, applications, system configurations, and other files.

---

## 🌐 3. Networking Resources

### 🔍 Example

A configured **IP address** and network interface.

### 🎯 Purpose

Networking resources enable the cloud server to establish connections with other systems and communicate with network-based services.

### ☁️ Importance in Cloud Computing

Networking provides the communication infrastructure required for users, applications, servers, and cloud services to exchange data.

### 🖥️ KillerCoda Environment

The Linux server uses **network interfaces and an assigned IP address** to establish communication with other systems and network resources.

---

## 🐧 4. Operating System

### 🔍 Example

**Ubuntu Linux**

### 🎯 Purpose

The operating system manages the underlying hardware resources and provides the platform required to execute applications, services, and system commands.

### ☁️ Importance in Cloud Computing

Linux is commonly used in cloud environments because of its **flexibility, reliability, efficiency, and strong support for server-based workloads**.

### 🖥️ KillerCoda Environment

KillerCoda provides a **Linux-based cloud environment** where users can execute terminal commands, manage system resources, and perform basic server administration tasks.
