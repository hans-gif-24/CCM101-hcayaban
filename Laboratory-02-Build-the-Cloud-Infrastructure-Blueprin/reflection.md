# ☁️ Cloud Infrastructure Laboratory Reflection

## 🎯 Overview

This laboratory activity helped me develop a better understanding of **cloud infrastructure and how its major components work together**. By using the KillerCoda Playground and Linux Terminal, I was able to explore a cloud-based Linux server and examine its CPU, memory, storage, networking, and operating system resources.

The activity allowed me to connect the concepts discussed in class with a practical cloud environment.

## ☁️ Cloud Infrastructure

I learned that cloud infrastructure consists of several interconnected components, including **compute, storage, networking, and operating systems**. Compute provides the processing power for applications, storage keeps important data and files, while networking allows users and systems to communicate.

Creating a basic cloud architecture for the fictional company **ARK** helped me visualize how these components interact within a cloud environment.

## 🐧 Linux in Cloud Computing

This laboratory also improved my understanding of **Linux and its role in cloud computing**. I used commands such as `lscpu`, `free -h`, `df -h`, `ip addr`, and `findmnt` to investigate the server's resources and configuration.

Through this activity, I became more comfortable using the Linux terminal and learned how system commands can be used for **monitoring, investigation, and basic server administration**.

## ☁️ Cloud Provider Comparison

Comparing **AWS, Microsoft Azure, and Google Cloud Platform** helped me understand that different providers offer similar infrastructure services under different names. I learned about services for compute, storage, networking, and identity management.

This showed me that understanding the **purpose of a cloud service** is more important than simply memorizing its name.

## 📝 Technical Documentation

I also learned the importance of creating clear and organized technical documentation. Using **Markdown, tables, diagrams, Git, and GitHub** allowed me to present my laboratory results in a structured and professional format.

Good documentation makes technical information easier to understand, maintain, and review.

## 🧠 Overall Reflection

Overall, this laboratory gave me valuable hands-on experience with **cloud infrastructure, Linux, networking, storage, and cloud service providers**. It strengthened my technical skills and helped me better understand how different cloud components work together.

> 💡 **Key Takeaway:** Cloud computing combines **compute, storage, networking, and other resources** to provide scalable and accessible services through the Internet. This activity gave me a strong foundation for learning more advanced cloud computing concepts.
