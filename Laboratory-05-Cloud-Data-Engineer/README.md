# ☁️ Laboratory 05 — The Cloud Data Engineer

## 🎯 Mission Overview

This laboratory introduced me to how cloud applications store and manage unstructured data using object storage. I used Docker to deploy **MinIO** and set up a basic storage environment for a photo-sharing application.

During the activity, I learned how to access the MinIO management console, create a storage bucket named `client-photos`, upload a sample file, and check whether the uploaded object was stored successfully. I also documented the process and results in my GitHub repository.

## 🎯 Objectives

The main objectives of this laboratory were to:

* Understand the differences between **Block Storage, File Storage, and Object Storage**.
* Deploy a MinIO server using Docker.
* Access the MinIO management console through port forwarding.
* Create an object storage bucket named `client-photos`.
* Upload a sample file and verify that it was stored correctly.
* Record the deployment steps and results using Markdown and screenshots.

## 🛠️ Tools and Technologies Used

* **KillerCoda:** Provided the Linux environment for performing the laboratory activities.
* **Docker:** Used to download and run the MinIO container.
* **MinIO:** Provided an S3-compatible object storage service for managing files and objects.
* **Web Browser:** Used to access and manage the MinIO console.
* **GitHub:** Used to organize, store, and maintain the laboratory documentation.
* **Markdown:** Used to write the technical reports, instructions, and reflection.

## 💡 Skills and Knowledge Gained

Through this laboratory, I learned how object storage works and how it differs from block storage and file storage. I also gained practical experience in deploying a storage service using Docker and configuring the necessary settings to make it accessible.

Additionally, I practiced setting environment variables, mapping network ports, creating storage buckets, uploading files, and verifying stored objects through the MinIO console. These activities helped me understand how cloud storage can be used to manage files for applications such as photo-sharing platforms.

This laboratory also improved my troubleshooting and technical documentation skills. By recording the commands, configurations, and results, I became more familiar with organizing project files and presenting my work clearly through GitHub.
