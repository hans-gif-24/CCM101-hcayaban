  Your task is to complete the onboarding mission using the KillerCoda Playground and create your personal

  Complete each checkpoint carefully. Every completed task represents a real-world responsibility of a cloud
  engineer.

## Linux Commands Used

  pwd – Checks the current location or working directory
  whoami – Shows the username of the current user
  hostname – Displays the name of the computer or system
  adduser – Used to create a new Linux user
  usermod – Used to modify or update a user account
  mkdir – Creates new folders or directories
  nano – Used to create and edit text files
  cat – Shows the contents of a file
  uname – Provides information about the Linux system and kernel
  lscpu – Shows details about the CPU
  free – Displays information about memory usage
  df – Checks the available and used disk space
