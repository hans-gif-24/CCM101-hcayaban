# Reflection

This laboratory helped me understand the basic use of Linux in a cloud environment. At first, I was not very familiar with using the terminal and different Linux commands, but as I followed the activities, I became more comfortable using them. I learned how to create a new user, navigate through directories, create folders and files, and check important system information.

I also learned how to organize my files and create a GitHub repository for my laboratory activities. Using Markdown files also helped me understand how to properly document my work. One of the things I found useful was learning commands such as `pwd`, `whoami`, `hostname`, `mkdir`, `nano`, `cat`, and `df`.

Overall, this laboratory gave me a better understanding of Linux, cloud environments, and GitHub. It also helped improve my confidence in using the command line and organizing my work. I know that these skills will be useful in our future Cloud Computing activities and other IT-related tasks.
