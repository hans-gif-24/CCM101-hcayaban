# ⚙️ Automation Research

## Mission 9: The Cloud Automation Engineer

### 1. 💻 Bash Script

A Bash script is a file containing Linux commands that can run in sequence to automate tasks. The `#!/bin/bash` line, also called the shebang, tells the system to use Bash to execute the script. It helps automate repeated tasks without entering every command manually.

### 2. 📦 Variables

Variables store values such as folder paths, filenames, and other information used by a script. For example, `$BACKUP_DIR` stores the name or location of the folder where backup files will be saved. Variables make scripts easier to update because their values can be changed without rewriting every command.

### 3. 🕒 Cron Job

A Cron Job is a scheduled task in Linux that runs commands or scripts at a specified time. It is useful for repeated tasks such as backups and system maintenance because these tasks can run automatically. This helps save time and reduces the chance of forgetting important operations.
